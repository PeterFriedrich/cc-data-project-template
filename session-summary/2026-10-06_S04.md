## 3. Technical Learnings
- **`check_decisions_log.py` accepts an amendment mark anywhere in the target
  row.** `IS_MARK` only matters at the start of a cell. I put
  `PARTLY AMENDED <date> (…)` at the **end** of the 2026-09-29 row, so the
  brief's first-sentence summary of that row isn't replaced by the mark.
  I confirmed the guard fails when the mark is removed.
- **`DEAD_ROW` in `make_brief.py` drops SUPERSEDED/RETRACTED/REVERSED rows.**
  It keeps AMENDED rows, which is right for a partial amendment.
- **The claude.ai GitHub picker lists only files on the default branch.** The
  owner ticks paths there; the source is drive-landscape, passing on the owner.
- **Two worktrees of one repo:**
  - `.githooks/pre-push` is per-worktree (`symbolic-ref`), with a shared
    `core.hooksPath`.
  - `handoff_gap.py` is per-checkout (ROOT is the script's worktree) and picks
    the newest handoff **by filename**.
- **Mods** (Claude Code v2.1.287+) are unsandboxed in-process plugin code. They
  can approve tool calls past `ask` rules and hooks. Their panes are invisible
  over Remote Control.
- **This handoff's first archive move broke `tests/test_copier.py`.**
  `copier.yml` excluded `/session-summary/*.md`, which is top level only, so
  `session-summary/archive/*.md` would have shipped into new projects.
  `template_drift.IGNORED`'s fnmatch `*` crosses `/`, so the two disagreed.
  The fix is in this PR: `- /session-summary/archive/*.md` added to
  `_exclude`. ⚠️ I first ran the suite as `pytest | tail -1 && …`, where the
  pipe hid the failure from `&&`, and the PR was opened red. Check the
  output, not the exit code of a pipeline.
- **Scratch venv for tests:** `$SCRATCH/v`, built from `requirements-ci.txt`.
  It's gone next session.
- **Bash quirk:** a heredoc to `$TMPDIR/…` failed (`/e.py: Permission denied`,
  TMPDIR unset). Write scripts to the scratchpad path explicitly.
