## 3. Technical Learnings
- ⚠️ **Don't falsify a test by inflating a constant that the fixture also
  uses.** I set `BRANCH_REMINDER_AT = 10**6` to watch the tests fail, but
  `_origin()` creates that many refs, so it hung past the 120 s timeout and I
  had to kill it. Mutate the comparison instead: `<` → `<=` fails 2 of 6.
- `handoff_gap.py` must run under the system **Python 3.6.8**, because the
  hooks fall back to it. f-strings are fine; `capture_output`/`text` are only
  used in tests. I checked with `python3 scripts/handoff_gap.py
  --session-start`.
- The scratch venv (`$SCRATCH/v`) went stale between days: `No module named
  pytest.__main__`. Rebuild it rather than debug it.
- `delete_branch_on_merge` is **false** on the template, `alberta-regional-viz`
  and `edmonton-permit-speed`. That's deliberate, per the owner.
  edmonton-tax-viz keeps it off because `check_todo_branch_refs` needs merged
  refs (its DECISIONS 2026-09-16).
