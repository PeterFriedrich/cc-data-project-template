## 3. Technical Learnings
- ⚠️ **`pgrep -af '<pattern>' || rm …` never deletes.** pgrep matches the
  wrapping `bash -c` command line, which contains the pattern, even with a
  `[5]` bracket trick, because the `rm` path holds the literal. Use
  `ps -eo pid,args | grep … | grep -v -e grep -e shell-snapshots`.
  `server`'s ongoing `disk-check.sh` uses `ls -l /proc/*/exe` and is fine.
