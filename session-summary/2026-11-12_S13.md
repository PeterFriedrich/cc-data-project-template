## 3. Technical Learnings
- **Fetch before reading another repo's trunk.** A local `origin/master` can be stale by minutes; the safety audit got one claim wrong this way. `git ls-remote` or `git fetch` first.
- **My own search error:** `grep ... | cut -c1-300` truncated lines past the match and I told the audit session a source didn't say "squash" when it did. Don't truncate before deciding a match is absent.
- `docs/AUDIT_*.md` can't live in the template repo (copier ships it; excluding the glob drops `AUDIT_LEDGER.md` rendered from `.jinja`). Briefs go in `/home/opc/research/cc-data-project-template/audits/`.
- A new template-only test file needs three edits: copier `_exclude`, `scripts/template_drift.py` `IGNORED`, `tests/test_copier.py` `TEMPLATE_ONLY` (the copier test pins the match).
- Strict xfails with `raises=AssertionError` keep a broken fixture from passing as a gap.
- `rc-session.sh <dir> <tmux> <rc-name> <model>` takes a model; worktree sessions need their auto-memory dir symlinked to the main clone's (`~/.claude/projects/-home-opc-<repo>-<role>/memory`).
- Project sessions can write `~/.claude/` via Bash with no prompt (this session did it for the symlinks).
- `server-ops/scripts/backup.sh` ends with `git push origin HEAD`, so it pushes any session commit left unpushed (told the owner).
- Merges here and in tax-viz/alberta/permit-speed are merge commits (99 of 100); squash is allowed but used once (alberta #16).
